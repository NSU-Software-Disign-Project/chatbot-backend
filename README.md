# Chatbot Editor — Визуальный редактор чат-ботов

## Описание и постановка задачи

**Цель проекта:**  
Создать web-приложение для визуального проектирования, настройки и тестирования чат-ботов. Пользователь может создавать проекты, собирать логику бота в виде блок-схемы, сохранять и запускать бота, а также делиться проектами с другими пользователями с разными уровнями доступа.

**Ключевые задачи:**
- Визуальное создание и редактирование логики чат-бота (drag-n-drop, блоки, связи).
- Хранение и управление несколькими проектами.
- Совместная работа и разграничение прав доступа (owner, editor, viewer, manager).
- Авторизация и аутентификация пользователей.
- Запуск и тестирование бота в реальном времени.
- Импорт/экспорт конфигураций.
- Масштабируемость и безопасность.

## Архитектура проекта

### Frontend (`chatbot-frontend`)

- **React** SPA с роутингом (`react-router-dom`).
- Визуальный редактор диаграмм на базе GoJS.
- Страницы: авторизация, список проектов, редактор диаграмм, чат.
- Работа с backend через REST API и WebSocket.
- Поддержка совместного редактирования (реалтайм).
- Управление проектами: создание, удаление, переименование, шаринг.
- UI/UX: drag-n-drop, модальные окна, toast-уведомления, адаптивность.

**Ключевые компоненты:**
- `Diagram` — визуальный редактор логики бота.
- `ProjectsPage` — управление проектами пользователя.
- `Messenger` — чат для тестирования бота.
- `SharingModal` — окно для управления доступом к проекту.

### Backend (`chatbot-backend`)

- **Node.js + Express** — REST API и WebSocket сервер.
- **Prisma** — ORM для работы с MongoDB.
- **Docker** — контейнеризация, запуск через `docker-compose`.
- **Caddy** — проксирование и HTTPS (опционально).
- **JWT** — аутентификация пользователей.
- **WebSocket** — для запуска и тестирования бота в реальном времени.
- **Модули**:
  - `boundary/routes` — REST endpoints (auth, user, projects, config).
  - `boundary/websocket` — WebSocket сервер для интерактивного чата.
  - `control/interpreter` — интерпретатор логики бота.
  - `control/db` — работа с базой данных через Prisma.
  - `entity/BotModel.ts` — описание модели бота.
  - `services` — обработка ошибок, JWT, shutdown.

**Структура данных:**
- **Project**: хранит схему (nodeDataArray, linkDataArray), владельца, sharedWith.
- **User**: email, пароль (хэш), имя, id.

## Ключевые решения

- **Визуальный редактор на GoJS**: обеспечивает гибкость и интерактивность для построения сложных логик чат-бота.
- **Prisma + MongoDB**: удобная работа с документ-ориентированными структурами (графы, массивы), простота миграций.
- **WebSocket для запуска бота**: мгновенная обратная связь при тестировании, поддержка интерактивных сценариев.
- **JWT и разграничение прав**: безопасность, возможность совместной работы над проектами.
- **Docker**: простота деплоя, воспроизводимость среды.
- **Модульная структура backend**: упрощает поддержку, тестирование и расширение функционала.
- **Возможность расширения блоков**: архитектура позволяет добавлять новые типы блоков (API, условия, циклы и т.д.).

## Особенности

- **Совместное редактирование**: несколько пользователей могут работать над проектом одновременно.
- **Гибкая система ролей**: owner, manager, editor, viewer.
- **Возможность запуска и тестирования бота прямо из редактора**.
- **Импорт/экспорт проектов**.
- **Масштабируемость**: легко добавить новые типы блоков, интеграции, расширить API.
- **Безопасность**: изоляция пользовательских данных, JWT, обработка ошибок, защита от несанкционированного доступа.
- **Контейнеризация**: быстрое развертывание в любой среде.

## Инструкция по запуску

### Запуск локально:

1. Склонируйте этот репозиторий себе удобным для вас способом, например:

```bash
git clone git@github.com:NSU-Software-Disign-Project/chatbot-backend.git
```

2. В ту же директорию склонируйте репозиторий фронтенда удобным для вас способом, например:

```bash
git clone git@github.com:NSU-Software-Disign-Project/chatbot-frontend.git
```

3. Перейдите в `chatbot-backend`
4. Запустите docker daemon на своём устройстве.
5. Выполните команду `docker-compose up -d`
6. Сайт доступен в браузере по адресу localhost
7. Остановить контейнеры командой `docker-compose down`
8. Для внесения изменений в конфигурацию запуска, создайте `.env` файл со следующей структурой: 

```
NODE_ENV=
DATABASE_URL=
CADDY_HTTP_PORT=
CADDY_HTTPS_PORT=
FRONTEND_URL=
BACKEND_URL=
REACT_APP_YJS_WS_URL=
```

## Пример использования

1. Зарегистрируйтесь и войдите в систему.
2. Создайте новый проект.
3. Откройте редактор, добавьте блоки (сообщения, условия, API, циклы и т.д.), соедините их.
4. Сохраните проект, запустите бота и протестируйте диалог.
5. Поделитесь проектом с коллегами, назначьте роли.
6. Экспортируйте/импортируйте проекты при необходимости.
